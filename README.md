# Digital SAT Math Bluebook Practice — September 2026 (Exam V1 & Exam V2)

An authentic, fully interactive web simulation of the College Board **Bluebook** digital testing application, designed specifically for the **September 2026 SAT Math** sections (Exams V1 and V2).

## 🚀 Live Demo & Hosting
The application is hosted via GitHub Pages:
**[Launch Digital SAT Math Bluebook Practice](https://elshod-gosling.github.io/sat-math-september-2026/)**

---

## 🌟 Key Features

- **Strictly SAT Math**: Excludes Reading & Writing sections; Math only.
- **Both Test Forms Included**:
  - **Exam V1**: Module 1 (22 questions) + Module 2 (22 questions) = 44 questions.
  - **Exam V2**: Module 1 (22 questions) + Module 2 (22 questions) = 44 questions.
  - **Total**: 88 questions with full answer keys, step-by-step solutions, and Desmos calculator shortcuts.
- **Integrated Desmos Graphing Calculator**:
  - Open/close at any time during the test.
  - Draggable & floating window across the screen.
  - One-click **Dock to Side** (split-screen mode) and **Undock**.
- **Authentic Bluebook Testing Tools**:
  - **Module Countdown Timer**: 35:00 timer per module with Hide/Show and 5-minute warning alert.
  - **Question Navigator**: Drawer modal showing answered, unanswered, current, and marked items.
  - **Mark for Review**: Flag questions to revisit later.
  - **Option Strikethrough**: Cross out eliminated multiple-choice options.
  - **Student-Produced Response (Grid-in)**: Formatted input supporting integers, fractions, negatives, and decimals with live fraction formatting.
  - **Official SAT Reference Sheet**: Pop-up reference sheet with 2D/3D geometry formulas and SVG diagrams.
  - **10-Minute Break Screen**: Timed break between Module 1 and Module 2.
  - **Official Scoring Scale**: Automatically computes your 200–800 score using the authentic 44-question conversion table from Page 37 of the exam forms.
  - **In-Depth Score Report**: Review all questions with step-by-step explanations and Desmos graphing tips.

## 💻 Tech Stack
- **Pure Vanilla HTML5 / CSS3 / JavaScript** (zero external build tools or server dependencies).
- **Desmos API v1.9** for graphing calculator functionality.
- **KaTeX** for SAT mathematical typography.
- High-resolution embedded vector graphics for coordinate planes and geometric figures.
